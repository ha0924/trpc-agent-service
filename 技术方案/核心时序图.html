核心消息时序图

抽象 IM 平台消息 → 幂等与会话调度 → Agent / Tool 执行 → Session / Memory 写入 → IM 回复
sequenceDiagram
    actor User as IM 用户
    participant IM as IM 平台
    participant CA as Channel Adapter
    participant GW as Agent Gateway
    participant SS as Session Scheduler
    participant WK as Agent Worker / Runtime
    participant ST as 共享存储
    participant EXT as LLM / Tool / MCP

    Note over User,GW: ① IM 入站与消息标准化
    User->>IM: 发送消息
    IM->>CA: 回调 / 事件投递
    CA->>CA: 验签、解析、身份映射
    Note right of CA: 提取 IM 原生 event_id / message_id
    CA->>GW: 统一消息 + 通道上下文

    Note over GW,SS: ② 幂等、目标 Agent 识别与会话调度
    GW->>ST: 原子创建入站幂等记录
    alt 首次收到该 IM 事件
      ST-->>GW: 已占位（processing）
      GW->>GW: 通过 Channel Binding 识别租户、Agent 与 Session
      GW->>SS: 提交 Session 执行任务
      SS->>SS: 同一 Session 串行，不同 Session 并行
      SS->>WK: 分派健康 Worker
    else 重复事件
      ST-->>GW: 已存在
      GW-->>CA: 不重复执行
      CA-->>IM: 快速确认回调
    end

    Note over WK,EXT: ③ Agent 执行与 Tool 调用
    WK->>ST: 读取 Session、Summary、Memory
    ST-->>WK: 返回共享上下文
    WK->>WK: 获取或构建 Agent Runtime
    Note right of WK: Runtime 内执行 Plugin / Guardrail / Callbacks
    WK->>EXT: Runner 执行 Agent / 调用 LLM
    loop Agent 需要调用 Tool 时
      EXT-->>WK: Tool Call
      WK->>EXT: 调用 Tool / MCP / 外部服务
      EXT-->>WK: Tool Result
      WK->>EXT: 继续 Agent 推理
    end
    EXT-->>WK: 最终回复

    Note over WK,ST: ④ 状态持久化与 IM 回复
    WK->>ST: 写入 Session Event，更新 Session State
    WK->>ST: 按策略写入 / 更新 Memory
    WK-)ST: 异步提交 Summary 更新
    WK-->>CA: 返回最终回复
    CA->>CA: 按 IM 能力转换文本 / 卡片 / 文件
    CA->>IM: 发送回复
    IM-->>User: 用户收到回复
    GW->>ST: 标记幂等记录完成，写入审计状态
    Note over CA,ST: 全链路携带 trace_id / request_id；发送失败时仅重试 IM 投递
