# 技术方案图稿

本目录先沉淀技术方案提交所需的两张核心图：

| 文件 | 用途 |
| --- | --- |
| `系统架构图.png` | 由 `docs/架构图1.0/agent-gateway-architecture.html` 在浏览器中直接渲染得到；布局、文字、组件与连线均保持该 HTML 当前呈现的样子，未重新设计或调整。 |
| `核心时序图.html` | 与系统架构图采用相同的 HTML + Mermaid 页面形式，展示“IM 用户发消息 → Agent 执行 → Tool 调用 → Session / Memory 写入 → IM 回复”的完整主时序。 |

## 图稿使用约定

- IM 通道保持抽象，可映射到企业微信、微信客服、Telegram 或其他支持 Webhook / 事件订阅的平台。
- 实线表达请求、执行或数据访问的主链路。
- 虚线表达配置、异步任务、治理和可观测等横切能力。
- 图中治理、监控、安全与故障恢复先体现为架构挂载点和关键边界；具体策略将在后续设计章节中补充。
- 核心时序图使用抽象 IM 平台；企业微信、微信客服、Telegram 等具体通道均可映射到这一流程。
