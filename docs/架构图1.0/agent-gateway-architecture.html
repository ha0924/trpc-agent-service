Agent Gateway 平台架构图

Sources → 接入适配 → 网关调度 → Agent 执行 → 共享存储 / 控制面 / 可观测
flowchart TB
      subgraph Sources["外部消息源"]
          IM["IM 平台<br/>企业微信 / 微信 / Telegram"]
          API["HTTP / OpenAI API"]
          UI["Web / AG-UI"]
          A2A["A2A Agent"]
      end

      subgraph Access["消息接入与适配层"]
          CA["Channel Adapter"]
          PA["Protocol Adapter<br/>API / AG-UI / A2A"]
          NM["统一消息模型<br/>身份映射 / 消息幂等"]
      end

      subgraph GatewayLayer["网关与调度层"]
          GW["Agent Gateway<br/>租户识别 / 鉴权 / 限流<br/>Agent 路由 / 版本与灰度路由"]
          SS["Session Scheduler<br/>同一 Session 顺序执行<br/>不同 Session 并行执行"]
      end

      subgraph WorkerLayer["Agent 执行层"]
          W1["Agent Worker 1<br/>tRPC-Agent-Go Runner"]
          W2["Agent Worker 2<br/>tRPC-Agent-Go Runner"]
          WN["Agent Worker N<br/>tRPC-Agent-Go Runner"]
      end

      subgraph Runtime["tRPC-Agent-Go 能力"]
          AG["Agent 编排<br/>LLM / Graph / Chain / Parallel"]
          TL["Tool / MCP / Skill"]
          GV["Plugin / Guardrail / Callbacks"]
      end

      subgraph StorageLayer["共享存储层"]
          SA["Storage Adapter / Router<br/>租户级后端选择"]
          SESSION["Session / Summary<br/>Redis / SQL"]
          MEMORY["Memory<br/>Redis / SQL / 外部服务"]
          KNOWLEDGE["Knowledge<br/>向量数据库"]
          ARTIFACT["Artifact<br/>对象存储"]
          AUDIT["Audit Log<br/>SQL / 日志存储"]
      end

      subgraph Control["平台控制面"]
          ADMIN["Admin API / 管理页面"]
          CONFIG["租户与资源配置<br/>Agent / Model / Tool / Channel<br/>Backend / Policy / Secret"]
      end

      subgraph Observe["可观测层"]
          TC["Telemetry Collector"]
          OBS["Trace / Metrics / Logs / Audit"]
      end
