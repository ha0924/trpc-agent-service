# 文档索引

基于 tRPC-Agent-Go 的多租户节点化 Agent 平台设计文档。

先看 [完成度台账.md](完成度台账.md)——唯一的完成度事实来源：按 README 五大块
逐项标注做到什么程度，并把未完成项与原因一并列出。它同时记录了实测发现并修复
的九个问题，那些是判断哪些结论可信的依据。

想按功能模块而非按要求条目查看，见 [功能清单.md](功能清单.md)：把题目拆成 12 个
模块 125 项功能，逐项标注状态。两份文档切分维度不同，交叉使用可发现「要求里没
点名、功能上却必须有」的遗漏。
